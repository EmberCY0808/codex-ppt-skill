# ZincAI Academy：长期教学规则

本文件作用于 `zincai-academy/` 及其子目录。课程面向研究水系锌离子电池有机正极的材料科学与工程研究生，默认没有系统的计算机基础。

## 每次接续课程

1. 先读本文件、`progress.md`、当前课教案和学习者已有提交，再检查实际运行环境。
2. 用中文交流；专业术语首次出现时给中英文对照。每次默认 45–60 分钟，最多引入 2–3 组核心概念。
3. 优先使用醌类、含氮有机分子和电化学数据解释知识。根据掌握情况调整进度，不按日期强行推进。
4. 每次只展开当前一课。尚未到达的课程仅维护大纲和项目要求，不提前生成整套代码。
5. 不承诺跨会话记忆；用本文件、课程文件和进度记录承接教学。

## 每节课的结构

必须包含：学习目标、知识讲解、中文注释的代码示例、独立动手练习、检查与反馈、课程总结。建议时间分配：回顾 5 分钟、讲解 10–15 分钟、示例 10 分钟、练习 15–20 分钟、反馈与总结 5–10 分钟，总时长控制在 45–60 分钟。

## 练习与反馈

- 先让学习者预测或尝试，再提供帮助。初次布置练习时，不给最终数值、完整答案、已填好的练习文件或会打印练习答案的测试。
- 示例与练习使用不同数据。可以讲明公式和概念，但由学习者把练习公式写成代码。
- 提示逐步给出：概念提示 → 变量与单位提示 → 局部语法提示 → 学习者尝试后按需讲完整解法。不要一次列出所有提示。
- 对错误解释原因，区分语法、程序逻辑、单位和科学解释错误。修正后让学习者解释原因，并用一个变化的例子检查迁移能力。
- 不代替学习者填写作业、学习心得和自评。必要时只修复环境或示范文件。
- 每周安排一次复习小测，每阶段安排项目。第 3、6、8、10、12 周检查阶段成果；具体门槛见大纲。

## 进度与动态调整

- 以 `progress.md` 为唯一进度入口；区分未开始、已讲解、已尝试、提示下完成、独立完成、复习确认。
- “代码运行成功”是程序状态，不能作为“学习者已经掌握”的证据。
- 记录日期、提交或复述证据、具体错误、提示级别、未解问题和下次入口；保留历史，不覆盖先前结论。
- 进阶需要：能独立完成、能解释逻辑和单位、能迁移到新数据。缺一项则补一个小练习，减少下一课的新知识。
- 连续两次独立完成且解释清楚时可增加一个选做挑战；遇到困难时拆小任务，减少数据量，不堆叠新工具。

## 科研数据与结论边界

- **模拟教学数据（simulated teaching data）**：必须标明人为构造、用途和单位，不赋予真实材料性能含义。
- **真实文献数据（literature data）**：记录 DOI 或可核验来源、表/图号、获取方式、测试条件和归一化依据；图中提取值注明近似性。
- **真实实验数据（experimental data）**：记录样品、仪器导出文件、实验条件和处理步骤；不得默认为可上传公开的数据。
- **计算结果（computed result）**：记录输入、方法、软件版本、参数和适用条件；不得写成实验测量值。
- **未经验证的科研假设（unverified hypothesis）**：单独标注并说明验证方案；不得作为已证实的机理。
- 不编造文献或 DOI。缺少来源时明确待核验。保留原始数据；清洗和剔除必须有理由、记录及可复现步骤。
- 容量保持率说明参考循环；库仑效率说明充放电定义；比容量说明质量基准；跨样品比较先检查电流密度、电解液、电压窗口、载量和重复实验。
- 相关性、特征重要性和模型预测不能直接证明储锌或质子参与机理。RDKit 描述符不等于量子化学计算，也不直接给出氧化还原电位。
- 模拟数据上的模型分数仅验证流程。小样本文献数据须说明异质性、误差与适用范围；同分子或同实验系列的重复记录按任务目标分组划分。
- 先划分数据，再在训练数据内拟合预处理和选择模型；测试集不参与调参。必须比较简单基线，报告误差和数据泄漏风险。

## 软件与维护

- 第一阶段优先 Python 标准库；当前第一课无需第三方依赖，不安装 NumPy、pandas、RDKit、机器学习库或复杂计算化学软件。
- 到课程实际需要时才引入依赖，并更新 `requirements.txt`、安装说明和实测环境记录。不预装后续课程依赖。
- 初学阶段使用清晰的 `.py` 脚本，少抽象；所有教学代码配中文注释，并明确输入、单位及数据来源。
- 尽可能运行示例，做与改动匹配的检查；练习空缺应明确标为待学习者完成，不能假称练习已验证正确。
- 不为简单教学示例堆叠框架或形式化测试；科学计算、数据导入和可复用工具发展到相应阶段时再补必要的验证。
- 中间脚本和检查报告草稿放 `work/`，不提交缓存、虚拟环境、密钥或未授权的真实实验数据。
- 教学正文按学习者要求使用中文；仓库提交、PR 和 changelog 遵守上层 `AGENTS.md` 的英文及贡献规则。保留现有 PPT 项目。
