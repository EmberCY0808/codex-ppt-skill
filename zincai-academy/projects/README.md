# 阶段项目任务

这里只建立任务和验收标准，当前不提供实现代码或项目答案。项目随课程逐步创建，每次复用已理解的内容。

## A：容量摘要器（第 3 周）

用 Python 标准库读取一份模拟循环数据 CSV，输出样品、数据来源、参考循环、目标循环、比容量和容量保持率。

交付：一个可运行脚本、输入示例及短说明。验收：换一份同格式文件仍可运行；对缺少参考记录或参考容量为零的情况给出清楚提示；学习者解释函数的输入、输出和单位。

## B：电化学分析报告（第 6 周）

从 CSV 生成容量—循环次数图和摘要，可增加 GCD 分析。用模拟数据先验证流程；若使用真实数据则先核验来源和实验条件。

交付：分析脚本、数据说明、带单位与条件的图、一页报告和必要检查。验收：保留原始文件；记录清洗理由；明确参考循环、充放电约定、活性物质质量基准及对比条件；有重复实验时报告离散程度，没有重复时不虚构误差棒。

## C：有机分子描述符表（第 8 周）

从少量已核验的醌类和含氮分子结构出发，计算基本分子描述符，比较结构差异，并提出一个待验证的结构—性能假设。

交付：分子标识与 SMILES 来源表、描述符 CSV、RDKit 版本和计算方法说明。验收：无效结构有记录；解释至少两个描述符；明确描述符为计算结果；区分结构假设与实验机理证据，不补造材料性能标签。

## D：性质预测与模型说明卡（第 10 周）

选择一个定义清楚的教学预测目标，比较简单基线与基础回归模型。默认模拟数据用于练习；有条件可比、来源可核验的真实数据时再替换。

交付：可复现的数据划分和计算脚本、基线与模型误差、模型说明卡。说明卡记录：数据来源和规模、标签单位、特征、划分依据、预处理范围、交叉验证、最终评估方法和适用范围。

验收：同分子或同实验系列重复记录按任务目标成组划分；预处理不接触留出测试数据；不使用测试集调参；数据量不足时明确评估不稳定。模拟数据上的误差不能证明对真实材料的预测能力，特征重要性不能证明机理。

## E：自己的科研助手（第 12 周）

必选范围：把已学会的电化学分析整理为一个本地小工具。按掌握情况，选加分子描述符查询或基础模型推断中的一项；不要求开发网站或使用付费 API。

交付：运行入口、输入样例、依赖说明、结果示例、必要检查和复现说明。验收：学习者用一份新输入独立运行；工具输出保留数据来源、单位和适用范围；对错误列名、缺失参考值等重要异常给出清楚提示。

AI 可协助解释报错、起草小段代码和检查文档；学习者必须说明关键代码，并用实际运行、单位核对或独立手算检验 AI 的建议。不要把 AI 生成的科研解释直接当作事实。
