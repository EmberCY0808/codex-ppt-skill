# 数据说明

本目录当前**只有模拟教学数据**，没有导入文献数据或真实实验数据。数据由导师人为构造，用于学习程序和公式，不代表任何真实分子的电化学性能。

## 第一课：`simulated/lesson01_capacity.csv`

- 来源类型：`simulated_teaching`，模拟教学数据（simulated teaching data）。
- 创建日期：2026-11-04。生成方式：手工指定两个教学数值；没有随机抽样、拟合或真实电池测试。
- 情境：假想水系锌离子电池有机正极 `Teaching-Organic-A`，同一样品、第 1 圈与第 100 圈的放电比容量。保持相同电流密度 0.2 A/g，假定相同电压窗口、电解液、温度及质量归一化基准。
- 第 1 圈为 200.0 mAh/g，第 100 圈为 180.0 mAh/g；质量基准为活性物质质量。未定义的实验条件不被补写成真实测试设置。
- 只有两个点，不能研究衰减路径、统计显著性、储锌/质子参与机理或长期稳定性；不能作为模型科研性能或论文结果。
- 文件采用 UTF-8、逗号分隔（comma-separated values, CSV），有表头，未设置缺失值。第一课只计算脚本中给定的数值，CSV 留待文件读取课程使用。

| 列名 | 含义 | 单位或约定 |
| --- | --- | --- |
| `sample_id` | 假想样品标识 | 不对应真实材料 |
| `cycle` | 循环次数 | 从第 1 圈计数，整数 |
| `specific_capacity_mAh_g` | 放电比容量 | mAh/g，按活性物质质量归一化 |
| `current_density_A_g` | 测试电流密度 | A/g，按活性物质质量归一化 |
| `data_origin` | 数据来源类别 | 固定为 `simulated_teaching` |

容量保持率（capacity retention）以第 1 圈作参考：目标圈的放电比容量 ÷ 第 1 圈的放电比容量 × 100%。相同比容量单位相消，结果为无量纲比值，以百分数表示。公式要求参考值非零；首圈活化等因素可能使科研任务需要不同参考循环，必须明确写出。

练习使用另一组人为构造数据，仅保存在第一课练习脚本和教案中，遵循相同模拟标识，不提供结果文件。

## 后续新增数据的要求

每个数据集至少记录：来源类别、文件与字段、单位、样品标识、实验或计算条件、缺失值约定、获取日期、处理步骤及用途边界。数据来源类别不能只藏在文件夹名称里，应在数据说明和结果报告中明确保留。

| 类别 | 必要来源记录 | 结论边界 |
| --- | --- | --- |
| 真实文献数据（literature data） | DOI/可核验链接、表/图号、提取方法、测试条件；图中提取值标近似 | 条件不同的数据不能直接当作同一个目标量 |
| 真实实验数据（experimental data） | 用户提供的仪器导出记录、样品、条件、质量和单位 | 原始文件保留；公开或上传前确认用户授权 |
| 模拟教学数据（simulated teaching data） | 人为构造或生成规则；若随机生成需种子和参数 | 只演示方法，不声称材料预测有效 |
| 计算结果（computed result） | 输入结构、方法、软件版本、参数和计算日期 | 不写成实验数据，不自动用于解释机理 |
| 未经验证的科研假设（unverified hypothesis） | 假设依据、待验证点和验证方案 | 单独记录，不作为已证实事实或测量标签 |

保持原始数据不变；清洗输出与原始文件分开，注明理由。不要把未授权的真实实验数据、个人信息或密钥提交到 GitHub。
