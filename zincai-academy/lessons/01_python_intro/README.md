## 2. 知识讲解（12 分钟）

### Python 能帮你做什么？

Python 是一种编程语言（programming language）。你可以把一套处理步骤写进以 `.py` 结尾的文件，再让 Python 按顺序执行。

在水系锌离子电池有机正极研究中，你以后可以用它整理电池测试仪导出的数据、计算容量保持率、画循环性能图，或批量比较分子的结构信息。今天先完成一件小事：让程序根据两次循环的比容量进行计算。

### 用变量保存数值

变量像实验记录中带名称的一格数据。例如，`initial_capacity` 表示参考循环的放电比容量，`later_capacity` 表示后续循环的放电比容量。`=` 表示把右侧的值赋给左侧的变量，并不是数学中的等式判断。

变量名本身不会检查单位，必须由我们写清楚。本课提到的比容量均为放电比容量（discharge specific capacity），单位都是 **mAh/g**，都按有机活性物质质量归一化。

### 用乘除法计算，再输出结果

Python 中，`/` 表示除法，`*` 表示乘法。`print()` 会把括号内的内容显示在终端中；引号内的文字会原样显示。代码中 `#` 后的文字是给人阅读的注释，不参与计算。

本课计算容量保持率（capacity retention），**参考循环固定为第 1 圈**：

> 容量保持率（%）＝第 100 圈比容量 ÷ 第 1 圈比容量 × 100

两个比容量的单位相同，相除后单位抵消。容量保持率是无量纲的比值，用百分数表示；程序输出的百分数数值需要标上 `%` 的含义。

## 3. 代码示例（8 分钟）

**数据类型：模拟教学数据（simulated teaching data）。** 下表由教师人为构造，不来自真实实验、文献或分子计算。

| 教学样品 | 循环次数 | 比容量（mAh/g） | 电流密度（A/g） |
|---|---:|---:|---:|
| Teaching-Organic-A | 1 | 200.0 | 0.2 |
| Teaching-Organic-A | 100 | 180.0 | 0.2 |

在这个教学设定中，两次记录来自同一模拟样品，质量归一化基准、电解液、电压窗口及其他测试条件保持一致。这里的条件一致是教学假定，不代表存在对应的真实实验。

先根据公式预测：输出的百分数应该大于、小于还是等于 100？然后打开 [example.py](example.py)，阅读中文注释，再运行。

从课程根目录 `zincai-academy/` 执行：

```bash
python3 lessons/01_python_intro/example.py
```

示例的核心语句是：

```python
# 用第 1 圈比容量作参考，计算百分数数值。
retention_percent = later_capacity / initial_capacity * 100

# 显示结果，并说明这里输出的是百分数。
print("相对第 1 圈的容量保持率（%）：", retention_percent)
```

预期输出：

```text
数据来源：模拟教学数据，非真实实验数据。
相对第 1 圈的容量保持率（%）： 90.0
```

这说明在给定的模拟数值中，第 100 圈比容量为第 1 圈的 90.0%。它不提供真实材料性能证据，也不能用于推断储锌机制或质子是否参与反应。
